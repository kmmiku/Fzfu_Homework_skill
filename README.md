# 福州外语外贸学院-实验报告模板skill

面向**福州外语外贸学院工科类学生**的课程实验报告（Word/.docx）撰写标准 skill：沿用课程模板保住排版，按「封面信息 → 六行信息表 → 实验过程图文 → 实验实践结论」的固定结构成文，并在交付前做**结构校验 + 渲染校验**。

**作者：GitHub@kmmiku**

**功能：** 把一次真实的实验/实训过程沉淀成符合本校课程模板格式的实验报告。skill 内置了三块可复用的知识：①模板版式约束（封面字号、合并单元格索引、图宽 15cm）；②「实验过程」的图文节奏（一条 10–20 字图注 + 一张截图，图注在上、图在下）；③截图时机清单与交付校验流程（重开文档核对图片数、LibreOffice 渲染核对分页）。覆盖虚拟机/操作系统安装、网络与安全实验、编程与数据库实验、嵌入式与硬件实验、AI 与数据处理实验等常见工科实验课型；也可用于「按上次报告的标准再写一份」这类延续性需求。

---

## 前提条件

- 支持 Skill 机制的 Agent 客户端（Claude Code、Codex、DSH 等），或任何能读 Markdown 规范的协作流程。
- 手头有三样东西收益最大：**实验指导书**（PDF/PPT）、**课程模板**（如 `实验报告模板\实验报告模版.docx`）、**往期报告**（`实验一.docx`、`实验二.docx`）。
- 纯问答、纯文案润色类需求无需本 skill。

## 安装与使用

### 第一步：获取 skill

```bash
git clone https://github.com/kmmiku/Fzfu_Homework_skill.git
```

### 第二步：安装到客户端 skills 目录

把 `skills/lab-report-cn` 整个目录放入你所用客户端的 skills 路径：

- Claude Code：`~/.claude/skills/lab-report-cn/`
- Codex：`~/.codex/skills/lab-report-cn/`
- DSH：`<工作区>/skill/lab-report-cn/`

目录内必须包含 `SKILL.md`，其 YAML frontmatter 提供 `name` 与 `description`，客户端据此决定何时加载。

### 第三步：触发

在写报告时直接提要求，例如：

- 「按上次实验报告的标准，把这次实验写成实验三」
- 「帮我把这些截图填进实验报告模板」
- 「实验报告写完了，帮我检查排版和图片数对不对」

客户端匹配 `description` 后自动加载本 skill，按模板版式产出 docx。

### 第四步：按校验清单交付

成文后必须跑完两步校验再交：**结构校验**（重开文档，核对图片数 == 图注条数、封面三段未被覆盖、信息表标签仍是「实验实践时间/地点」）与**渲染校验**（LibreOffice 渲染首页/中间页/末页，确认封面不折行、图注在图片上方且未被拆页、结论与签名栏在最后一页）。

## 报告结构规范（skill 摘要）

### 封面（3 段，居中/两端对齐沿用模板）

```
        {{课程名}}       课程课内实验实践报告
学院：     {{学院}}     年级：    {{年级}}       专业：   {{专业}}
班级：   {{班级}}        姓名：  {{姓名}}                  学号：  {{学号}}
```

字体 10.5pt（五号）——字号超过 10.5 会让较长的专业名称折行，破坏版式。

### 信息表（模板固定 6 行）

| 行 | 内容 | 关键点 |
|---|---|---|
| r0 | 实验实践时间 / 地点 | 时间写 `cells[2]`、地点写 `cells[4]`，`cells[0]==cells[1]` 是合并标签格 |
| r1 | 实验实践名称 | 格式「实验N：&lt;实验名称&gt;」，名称取自指导书标题 |
| r2 | 实验实践目的 | 逐条 `●` 开头，来源=指导书「实验目的」 |
| r3 | 实验实践设备与仪器 | 列「计算机/宿主软件/平台与版本/镜像」 |
| r4 | 实验过程（整行合并） | 图文混排，本 skill 的核心 |
| r5 | 实验实践结论 + 指导教师签名 | 结论首行缩进 21pt，末尾留空行 + 签名栏 |

### 「实验过程」图文节奏

`实验过程：` → 每步 **图注段（10–20 个汉字，动词开头）+ 图片段（居中，宽 15cm）** → 下一步。一条图注只对应一个动作/一个界面，图注在上、图在下。

合格：`上传Windows与CentOS安装镜像`、`配置2核CPU、4096MB内存与20GB磁盘`、`安装完成进入Windows10桌面`
不合格：`截图1`（无信息）、`点击下一步然后选择自定义安装并新建分区应用确定`（超长）

## 三条铁律

1. **模板优先**：永远基于课程模板改，不新建空白文档；往期报告是排版与文风基准，不自创版式。
2. **点完就截**：对话框一旦关闭无法复现，向导每一步都要落地一张图；进度类画面抓一次带百分比的即可。
3. **双校验**：结构校验（重开文档数段落/表格/图片）+ 渲染校验（LibreOffice 看分页），两步都过才算交付。

## 隐私说明

- 本 skill 是**模板**，自身不包含任何具体姓名、学号、学院、专业、班级、实验室门牌或账号名，全部用 `{{占位符}}` 表示。
- 生成报告时，个人信息从同目录的往期报告与用户口述中读取并当场填入；**不写进脚本、不写进仓库**。
- 仓库内只放规范与脚本骨架，不放任何人的真实报告文件。

## 常见坑（skill 已内置，此处速查）

- 模板单元格合并：`row.cells` 会把同一个合并格重复返回，写错索引就会覆盖「实验实践时间」标签。
- `_Cell` 没有 `add_run`，只能 `cell.paragraphs[0].add_run(...)`。
- 图片一律 `width=Cm(15.0~15.2)`，表格内可用宽度约 15.5cm，别按原始像素宽插。
- 中文必须显式设 `rFonts` 的 `eastAsia`，否则字体回退。
- Word 打开过会留 `~$xxx.docx` 锁文件，写入前确认 WINWORD 未运行。
- PowerShell 5.1 读 UTF-8 无 BOM 的 `.ps1` 会乱码报解析错误；脚本里别写中文，或存成带 BOM。
